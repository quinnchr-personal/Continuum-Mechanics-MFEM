1D Stefan Problem Restated for an Ablating Material
==================================================

This file states a classical 1D Stefan-type moving-boundary problem in ablation language,
for a semi-infinite solid, together with its exact similarity solution.

Problem statement
-----------------
Consider a semi-infinite solid occupying

    -∞ < x ≤ s(t),     t > 0,

where x = s(t) is the receding surface. The solid extends infinitely inward.

Unknowns:
    - Temperature T(x,t) in the solid
    - Surface position s(t)

Governing equation
------------------
Assume constant material properties and pure conduction in the solid:

    ρ c ∂T/∂t = k ∂²T/∂x²,      x < s(t),  t > 0

or equivalently

    ∂T/∂t = α ∂²T/∂x²,          α = k / (ρ c)

where
    ρ   = solid density
    c   = specific heat
    k   = thermal conductivity
    α   = thermal diffusivity

Boundary conditions
-------------------
1. Surface temperature:

    T(s(t), t) = T_a,           t > 0

   where T_a is the ablation temperature.

2. Far-field condition in the undisturbed material:

    T(x,t) → T_0   as x → -∞,   t > 0

   where T_0 is the initial temperature.

Surface recession law (Stefan condition)
----------------------------------------
The conductive heat arriving at the surface is assumed to go entirely into material removal:

    ρ L* v_s = -k (∂T/∂x)|_(x=s(t))

where
    v_s = -ds/dt > 0     is the recession speed
    L*                  is the effective heat of ablation

Equivalently,

    ρ L* (-ds/dt) = -k (∂T/∂x)|_(x=s(t))

Initial conditions
------------------
Initially the material is undisturbed and the surface is at x = 0:

    T(x,0) = T_0,        -∞ < x ≤ 0
    s(0)   = 0

Exact similarity solution
=========================

Surface position
----------------
The receding surface is

    s(t) = -2 λ √(α t)

where λ > 0 is a constant determined from the Stefan number relation below.

Temperature profile
-------------------
The exact temperature field in the solid is

    T(x,t) = T_0
             + (T_a - T_0)
               erfc( (s(t) - x) / (2√(α t)) ) / erfc(λ),

for x ≤ s(t), t > 0.

This satisfies
    T(s(t), t) = T_a
and
    T(x,t) → T_0 as x → -∞.

Stefan number
-------------
Define the Stefan number in ablation form as

    Ste = c (T_a - T_0) / L*

Equation for λ
--------------
The similarity parameter λ is determined by the transcendental equation

    Ste = √π λ exp(λ²) erf(λ)

or equivalently by finding the positive root of

    f(λ) = √π λ exp(λ²) erf(λ) - Ste = 0

Interpretation
--------------
This is the conduction-limited ablation analogue of the classical single-phase Stefan problem.
It is an exact solution for the idealized model above, and it is useful as a verification case
for:
    - 1D transient heat conduction
    - moving-boundary / recession implementation
    - coupling between surface heat flux and recession rate
    - ALE or moving-mesh formulations in the Stefan limit

Assumptions
-----------
This exact solution assumes:
    - semi-infinite solid
    - constant ρ, c, and k
    - no pyrolysis
    - no gas flow in the solid
    - no surface chemistry
    - no radiation losses
    - no volumetric source terms
    - sharp receding surface
